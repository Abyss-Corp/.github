## `> contribution.protocol`

```bash
$ git clone https://github.com/Abyss-Corp/<project>.git
$ cd <project>
$ cat CONTRIBUTING.md   # per-project rules of engagement
```

**Ground rules for every project in this org:**

1. **No decorative code.** Every service, container, and script has to justify why it's real infrastructure, not a demo.
2. **Document the failure modes.** A README that only shows the happy path isn't finished.
3. **Security is not an afterthought.** DevSecOps means the hardening step ships with the feature, not after.
4. **Commit messages tell the truth.** `fix: thing` is not a commit message.
